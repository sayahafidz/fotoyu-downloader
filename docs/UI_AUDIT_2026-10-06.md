# Mobile-first audit and verification

## Findings addressed

1. Import promised one-click usage although it required bookmark setup (R-16, R-36). The import screen now states setup requirements and labels each actual action.
2. Gradients, emojis, glass surfaces, glow and repeated shadowed cards competed with photo content (R-01, R-04, R-10, R-12). Solid surfaces, system type and a restrained accent replace the primary UI treatments.
3. Gallery toolbar overloaded one narrow row with unrelated tools (R-03, R-05). Search, photographer filter and selection are separate rows; processing and collage tools disclose progressively.
4. Select-all replaced other selections, losing work across filters (R-26). It now adds or removes only visible photos. Hidden selections remain counted and explained.
5. Gallery unmounted during downloads, resetting its state (R-27). The gallery persists during processing, with cancel/progress feedback.
6. Small targets, nested photo buttons and keyboard-inoperable list previews (R-03, R-32). Photo preview and selection are sibling native buttons; primary controls target 44–48px.
7. Clipboard and image failures were silent (R-27). Import clipboard fallback, file errors and photo retry are visible.
8. Dialogs lacked consistent Escape, scroll lock and focus restoration (R-32). A shared dialog hook handles guides, collage and progress; photo viewer uses the same lifecycle.
9. Collage regenerated continuously because its photo array changed on every render (R-26). Input photos are memoized. Rendering/share errors are visible, export is disabled during processing, invented event text is removed.
10. Downloads were labeled as direct-to-gallery (R-36). UI now explains browser downloads and ZIP extraction.
11. Install prompt could obscure the download bar (R-03). It is inline and hidden while browsing photos.
12. Unsupported provider/pricing claims and dead OpenAI selection (R-17, R-26, R-36). Provider settings are managed on the server; OpenAI image-edit and custom chat-image router paths are implemented.

## Design read

Mobile photo utility for event attendees, native-feeling and photo-led. ENERGY 1 / RHYTHM 2 / MOTION 1. See `DESIGN.md` for one-line purpose statements.

## Browser evidence

Automated Chromium against the local production build, using fixture cart data and fixture image responses:

- Invalid JSON submission displays an error; valid cart data opens the gallery.
- Import, gallery and prompt screens do not horizontally overflow at 320, 390, 768 or 1280px.
- Android guide opens and closes with Escape.
- Selection remains across photographer filtering and select-visible adds to it.
- Grid photo opens; arrow navigation and zoom work; Escape closes.
- List photo opens with keyboard Enter.
- Download options expand; quota loads; OpenAI provider selection works.
- Collage renders to an enabled export action instead of looping.
- ZIP download emits a browser download event; returning to import works.
- Prompt variant selection changes the displayed prompt; theme toggle changes theme.
- No browser page exceptions during those checks.

Screenshots were captured but could not be visually inspected with this model's image capabilities. This is functional/responsive evidence, not a claim of a complete visual accessibility audit. Real provider outputs, native mobile share/install prompts, and live CDN availability require device/credential verification.

## Delivery gate

- Hard gate: functional/responsive checks above pass; content uses real actions and counts; keyboard dialog behavior verified. Exhaustive contrast and every-control/device coverage remain unverified.
- Purpose gate: primary design decisions are documented in `DESIGN.md`; photographic content supplies the identity rather than decorative assets.
- Liveliness: calm hierarchy, content-first composition, accent only for action and selection; no decorative entrance choreography.
- Craftsmanship: production build and automated interaction checks pass. Provider decoder and Redis quota tests provide server behavior evidence; live provider success remains unverified.
